## 前置準備（跑模擬之前算一次）

先針對兩種粒子分別用米氏理論算出各自的散射振幅函數 $S_1(\theta),S_2(\theta)$，由此得到：

- 各自的散射截面 $\sigma_{s,i}$、吸收截面 $\sigma_{a,i}$
- 各自的相位函數 $p_i(\theta)$（即 $S_{11}(\theta)$），轉成累積分布函數（CDF）存成查表，供之後反演抽樣散射角
- 若要追蹤偏振，額外算出完整 Mueller 矩陣的四個獨立元素 $S_{11},S_{12},S_{33},S_{34}$

再依粒子的數密度 $N$ 算出混合介質的巨觀係數： $\mu_s=N\sigma_{s}$ 、 $\mu_a=N\sigma_{a}$ 、 $\mu_t=\mu_s+\mu_a$。

## 光子封包主迴圈

每個光子從入射點、入射方向、初始權重 $W=1$（若追蹤偏振則再帶一個初始斯托克斯向量）開始，重複以下步驟直到被終止：

**第一步：抽自由路徑。** 用 $s=-\ln(\xi)/\mu_t$ 抽出這次要走的距離，算出候選位置 $\mathbf{r}_1=\mathbf{r}_0+s\hat{d}$。若濃度場空間不均勻，改用 Woodcock delta-tracking。

**第二步：邊界檢查。** 算出沿目前方向走到容器邊界的距離 $s_{boundary}$，跟 $s$ 比較：

- $s<s_{boundary}$：候選位置在液體內部，是有效碰撞點，進入第三步
- $s\ge s_{boundary}$：光子先到邊界，跳到第四步處理邊界事件

**第三步：碰撞事件（在液體內部）。** 扣權重 $\Delta W=(\mu_a/\mu_t)W$，然後用對應粒子的相位函數 CDF 反演抽出散射角，更新方向，用該粒子的 Mueller 矩陣更新斯托克斯向量 
$$\mathbf{S}_{new} = \mathbf{M}_i(\theta) \mathbf{R}(\psi) \mathbf{S}_{old}$$ 
處理完後回到第一步，重新抽下一段自由路徑。

**第四步：邊界事件。** 用 Fresnel 反射係數 $R(\theta_i)$（由入射角、兩側折射率算出）抽機率分岔：

- 反射：方向按鏡面反射公式更新，光子留在液體內部，回到第一步繼續走
- 穿透：權重記入偵測器角度分箱統計（穿透率、角分布），終止這條路徑

**第五步：權重剪枝檢查。** 每輪迴圈結束時檢查權重 $W$ 是否低於門檻，若低則觸發 Russian roulette：以 $1/m$ 機率存活並放大權重 $m$ 倍，否則歸零終止（不記統計）。

## 統計收集

每條光子路徑終止（穿透邊界或被 roulette 淘汰）後，把有效貢獻累加進：角度分辨的出射光強分布、每個光子最後散射所屬的粒子種類、若追蹤偏振則還有出射光的斯托克斯向量分布。這些統計最終用來反推兩種粒子的比例與尺寸分布特徵。
