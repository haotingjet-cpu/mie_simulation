# Mie scattering Monte Carlo workflow

本文件摘要說明目前程式實際執行的模擬流程。參數定義、各階段計算細節、
輸出解讀及目前限制請見 [`docs/execution-flow.md`](docs/execution-flow.md)。

## 模型與單位

- 模擬區域是半徑 `RADIUS_NM` 的無限長圓柱，圓柱軸沿全域 Z 軸。
- 光子從圓柱中心沿全域 +X 方向入射。
- 長度與位置一律使用 nm；截面使用 nm²；巨觀係數使用 nm⁻¹。
- 粒子濃度欄位 `molarity_mol_nm3` 的單位是 mol/nm³。粒子數密度為
  `N = concentration × Avogadro`，不再做 mol/L 換算。
- 粒子折射率需是絕對折射率；Mie 計算會換成相對於背景介質的折射率
  `m_rel = m_particle / N_MEDIUM`，尺寸參數則以介質波長計算。

## 執行步驟

1. `find_solution_mu_sta` 由 Mie 消光效率、粒子幾何截面與粒子數密度計算
   `mu_s`、`mu_t` 及 `mu_a`。若球形粒子的名義體積分率大於 1，會停止並回報錯誤。
2. 預先建立角度查表：計算每個角度 bin 的 Mueller 矩陣，使用 `S11 sin(theta)`
   建立 CDF，供每次體積碰撞抽樣散射天頂角。方位角目前均勻抽樣。
3. 依 `PHOTON_CONST` 個數逐一建立光子。初始位置為原點、方向為 +X、
   權重為 1、Stokes 向量為 `(1, 0, 0, 0)`，且標記為尚未散射。
4. 每段路徑依 `s = -ln(1-U)/mu_t` 抽樣。若候選點在圓柱內，視為體積碰撞；
   否則求圓柱側壁交點並以 Fresnel 機率決定反射或透射。
5. 體積碰撞時更新散射方向、偏振狀態與光子權重，並標記光子已散射。
   權重低於門檻時使用 Russian roulette 決定是否繼續。
6. 透射離開圓柱的光子依出射角 bin 累積加權強度；未散射與至少散射一次的光子
   分別記錄。
7. 將兩個直方圖除以模擬入射光子數及對應環帶立體角，轉成每個入射光子的
   每 sr 強度，並輸出比較圖。

## 模擬完成後的解讀

輸出圖是按出射角分箱的加權強度，不是單顆粒子的純 Mie 相函數。圓柱壁折射、
有限角度分箱及 Fresnel 反射都會改變出射分布。需要與 `S11` 比較時，應設計
不含折射影響的對照模擬，並確認比較的是相同角度定義及歸一化方式。

目前 Fresnel 邊界分岔採用非偏振光的平均反射率；邊界反射／透射沒有完整更新
Stokes 向量。方位角也採均勻抽樣，因此高階多重散射的偏振相依抽樣尚未完整實作。
